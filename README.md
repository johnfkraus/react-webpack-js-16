# react-webpack-js-16

This repository demonstrates the phased migration of a very simple React version 16 application to the current version 19 of React.

This repository has the following branches:

## react16

The starting point.

## react17

The result of migrating React 16 to React 17.

## react18

The result of migrating React 17 to React 18.

## react19

The result of migrating React 18 to React 19.

## react19vite

The result of migrating the frontend build architecture from Webpack to Vite.
